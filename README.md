# Round Robin CPU Scheduling Simulator

**Description**: An Operating Systems group assignment focused on Round Robin CPU Scheduling using Python.

**Objective**: Develop a simulator that demonstrates round robin scheduling, visualizes process execution, and provides metrics for analysis.

**Technologies Planned**:
- Python
- Streamlit
- Pandas
- Matplotlib

**Team Size**: 2 members
